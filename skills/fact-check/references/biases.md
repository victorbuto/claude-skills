# Искажения для проверки отчётов

Полный каталог: `.claude/skills/cognitive-bias-detector/references/biases-catalog.md`. Здесь только то, что ловит разрыв между данными и выводом в кабинетном исследовании. Проверка идёт без поиска в интернете: только текст отчёта и здравый смысл.

Перед проходом зафиксировать **целевую аудиторию исследования**: из цели и задачи в шапке файла, из SPICE (Perspective), из формулировки заказчика. Каждый вывод сверяется с ней.

Где искать: выводы и интерпретации. Разделы «Главное», «Что из этого следует», «Инсайты», «Преломление под задачу», «Итог», а также любые фразы вида «значит», «поэтому», «это подтверждает», «отсюда следует». Отдельные числа не трогать, их проверяет фактчек.

## Блок А. Число без контекста

| Искажение | Вопрос к тексту | Пример из отчётов |
|---|---|---|
| **Базовый процент** | Процент дан без абсолюта или базы, и на нём стоит вывод о масштабе? | «+800% готовых рыбных блюд за два года» при доле 1–2% категории → «ключевой тренд» |
| **Иллюзорная закономерность** | Тренд или закон выведен из двух точек? | «Граница премиума поднялась с 1000 до 3000 за два года» → «структурная премиализация» |
| **Ошибка выжившего** | Вывод сделан по тем, кто виден, без тех, кто выбыл? | Бенчмарки агентств: только живые сайты с позиционированием, закрывшиеся не учтены → «позиция на пересечении свободна» |

## Блок Б. Причина из соседства

| Искажение | Вопрос к тексту | Пример из отчётов |
|---|---|---|
| **Смешение причины и следствия** | Два числа или события стоят рядом и выданы за причину? | «Подняв чек на 15,6%, компания обвалила набор на 39%» |
| **Причинность задним числом** | Объяснение построено после факта под уже известный исход? | «Регуляторика сделала консолидацию неизбежной» |
| **Лжеобъяснение** | Объяснение сработало бы при любом исходе, ничего не запрещает? | «Потребитель не отказывается от рыбы, он отказывается её готовить» объясняет и рост, и падение полуфабрикатов |
| **Авторитет вместо данных** | Мнение эксперта стоит там, где нужен замер, и на нём построен вывод о рынке? | Цитата сомелье «российского премиума с историей нет» → тренд с силой 9/10 |

## Блок В. Вывод из того, что попалось

| Искажение | Вопрос к тексту | Пример из отчётов |
|---|---|---|
| **WYSIATI** | Вывод сделан по найденному, пробелы поиска в нём не учтены? | «Три вектора вместе не занял никто» по выборке сайтов; «детское питание с рыбой — пустая полка» |
| **Подмена вопроса** | Ответили на более простой или соседний вопрос вместо заданного? | Данные по винам от 3000 руб. вместо заданных от 10 000; премиальный алкоголь вместо коллекционного вина |
| **Предвзятость подтверждения** | Сигналы только за гипотезу клиента, контр-сигналы отсутствуют или стоят для галочки? | «Это подтверждает основную гипотезу клиента»; один контр-сигнал на восемь подтверждающих |
| **Иллюзия достоверности через детали** | Точность числа создаёт доверие, которого нет у его источника? | «R$ 906 тыс. за одно место», «средний чек 66 310 руб.» из пересказов в СМИ |
| **Чужая аудитория** | Вывод о целевой аудитории исследования построен на данных про другую: шире, уже, другая страна, другой сегмент, другой доход? | «76% россиян хотят есть рыбу чаще» → вывод о покупателях полуфабрикатов; «Gen Z в США — аудитория снэков» → тренд для РФ; «5% россиян готовы платить больше 2000» → вывод о коллекционерах вин от 10 000; «одинокие потребляют 39,9 кг» → аргумент про семьи с детьми |

Чужая аудитория — самое частое искажение в отчётах под заказчика: данные про всех тянут к узкому сегменту, а данные про чужой рынок к российскому. Проверять у каждого вывода отдельно, даже если числа в нём верны.

## Два финальных вопроса к каждому выводу

- **Что этот вывод запрещает?** Если он совместим с любыми данными, это не вывод, а формулировка. Отметить как лжеобъяснение.
- **Есть ли третья альтернатива?** Если вывод подан как выбор из двух («либо дорогое российское, либо единственное с прошлым»), спросить, какие варианты не рассмотрены.

## Правила

- Искать искажение, а не натягивать список на текст. Нет искажения — нет блока.
- Одно место может нести два искажения, тогда два блока.
- Указывать вывод дословно, не пересказом.
- Не дублировать фактчек: если проблема в самом числе (не тот период, не тот объект), это флаг фактчека, не искажение. Искажение — когда числа верны, а вывод из них не следует.
