# Примеры разметки утверждений

Каждое утверждение получает две метки: тип (число / признак / поведение / наличие / событие / связь / смешанное) и модальность (факт / мнение / прогноз / норма).

## Разметка по типу

| Утверждение | Тип | Почему |
|---|---|---|
| «Выручка YDUQS за 2025 год составила R$ 5 521 млн» | Число | Величина с единицей и периодом |
| «Средний чек в EAD у Cogna — R$ 269» | Число | Предикат — мера субъекта |
| «Alura — крупнейшая технологическая эдтех-компания Бразилии» | Признак | X является Y, критерий «крупнейшая» не задан |
| «Яндекс 360 — флагманский продукт российского облачного хранения» | Признак | Оценка без критерия |
| «Crowd DNA работает на 75+ рынках» | Признак | Место, качественная характеристика |
| «Холдинги скупают медицинские мандаты» | Поведение | Повторяется, даты нет; проверяется по нескольким сделкам |
| «82% ценителей пьют вино дома» | Поведение | Регулярное действие с квантором; карточка числа заполняется дополнительно |
| «Половина покупок премиального алкоголя — подарок» | Поведение | Мотив покупки с долей; заявлено операторами рынка, не замерено |
| «Подарок руководителю выбирают по истории вокруг вина» | Поведение | Паттерн без доли, один источник (дистрибьютор) |
| «Граница премиума поднялась» | Число | Изменение без величины, флаг: величины нет |
| «Крупных венчурных раундов 2025 года не найдено» | Наличие | Утверждение об отсутствии, зависит от полноты поиска |
| «У «Массандры» есть непрерывный ряд миллезимов с 1938 года» | Наличие | Утверждение о существовании |
| «Декрет 12.456 вышел 19 мая 2025 года» | Событие | Что-то произошло в момент t |
| «В 2024 году дистанционное обучение впервые обогнало очное» | Событие | Перелом с датой; внутри два числа, но суть — момент |
| «Cogna зарабатывает за квартал больше, чем весь эдтех привлёк за десять лет» | Связь / сравнение | Два конца, разные метрики (выручка и инвестиции) |
| «Подняв чек на 15,6%, компания обвалила набор на 39%» | Связь / причина | Два числа соединены причиной |
| «Вина дороже 3000 руб. дают 32,5% выручки АСТ» | Связь / часть–целое | Доля от целого, целое — выручка АСТ |

**Правило:** тип задаёт предикат. Мера субъекта → число. Регулярное действие → поведение, даже с долей; карточка числа при этом заполняется. Один раз с датой → событие. Соединяет два субъекта → связь, концы размечаются отдельно.

## Разметка по модальности

| Утверждение | Модальность | Почему |
|---|---|---|
| «В высшем образовании учатся 10,23 млн человек» | Факт | Настоящее время, проверяемо |
| «React лучше Vue для enterprise» | Мнение | «Лучше» без критерия |
| «Ностальгический код в премиуме читается как отсталость» | Мнение | Оценка эксперта |
| «Рынок вырастет до 15,6 млрд к 2034» | Прогноз | О будущем |
| «Российского премиума с историей не появится ближайшие 20 лет» | Прогноз | О будущем, хоть и звучит как факт |
| «Педагогические программы обязаны давать 70% нагрузки очно» | Норма | «Обязаны», есть документ |
| «П. 16 ст. 270 НК запрещает списать подаренный алкоголь в расходы» | Норма | Статья кодекса |

**Правило:** о будущем → прогноз. Оценочное слово без критерия → мнение, даже рядом с цифрами.

## Оценка и отбор

Задача: отчёт по рынку EdTech Бразилии для решения о выходе. Четыре утверждения из текста:

| Утверждение | Тип / мод. | Влияние | Релев. | Спорность | Провер. | Решение |
|---|---|---|---|---|---|---|
| «Рынок EdTech Бразилии — 6 млрд долларов в 2025» | число / факт | 3: цифра уйдёт в презентацию | 3 | 3: вендорская оценка, методология закрыта, вторая оценка похожа на производную | 2: сам отчёт за пейволом, есть пересказы и отчётность холдингов для сверки снизу | проверить первой |
| «66,3% эдтех-стартапов никогда не получали инвестиций» | поведение / факт | 2: подкрепляет вывод о бедности сегмента | 2 | 2: опрос ассоциации, N=368, кто отвечал — неясно | 3: исследование опубликовано | проверить |
| «Gran Cursos: 80% прокуроров Сан-Паулу — наши выпускники» | число / факт | 1: иллюстрация | 1 | 3: самоотчёт компании | 1: сверить не с чем | метка, не проверять |
| «Alura — крупнейшая технологическая эдтех-компания» | признак / мнение | 1 | 2 | — | — | метка |

Первое утверждение уходит в проверку первым: влияние 3 и спорность 3. Третье не проверяется даже при спорности 3: влияние 1 и релевантность 1.

## Смешанные утверждения

Фраза с несколькими типами не обязательно режется. Если части связаны по смыслу, она размечается как «смешанное» с перечнем типов и проверяется по частям внутри одной записи. Резать стоит, когда части никак не связаны или одна часть факт, а другая мнение.

**«Подняв чек на 15,6%, Ânima обвалила квартальный набор на 39%»** → смешанное: число + число + связь-причина / факт
- Часть 1: чек +15,6% → число / факт
- Часть 2: набор −39% → число / факт
- Часть 3: падение вызвано ростом чека → связь-причина / факт в чужом голосе (аналитик Itaú)
- Общий вердикт по слабейшей части: числа сверяются с отчётностью, причина держится на одной цитате → ЧАСТИЧНО. Отчёт вправе писать «аналитик связывает», не «обвалила».

**«Холдинги скупают медицинские мандаты, потому что медицина даёт чек в 7,6 раза выше дистанционного»** → смешанное: поведение + связь-сравнение + связь-причина / факт
- Часть 1: холдинги скупают мандаты → поведение, проверяется по нескольким сделкам
- Часть 2: чек в 7,6 раза выше → связь-сравнение двух чисел (R$ 2 052 и R$ 269), один источник, один период
- Часть 3: скупают, потому что чек выше → связь-причина, вывод автора отчёта

**«GPT-4 прошёл bar exam и скоро заменит юристов»** → лучше разрезать: части не связаны по модальности
- Утверждение 1: «GPT-4 прошёл bar exam» → событие / факт
- Утверждение 2: «GPT-4 заменит юристов» → связь-причина / прогноз

**«Tesla продала 1,8 млн машин в 2023 и доминирует на рынке EV»** → лучше разрезать: факт и мнение
- Утверждение 1: «Tesla продала 1,8 млн машин в 2023» → число / факт
- Утверждение 2: «Tesla доминирует на рынке EV» → признак / мнение («доминирует» без критерия)

## Пограничные случаи

### Кажется фактом, но признак
| Утверждение | Почему признак |
|---|---|
| «Go — быстрый язык» | «Быстрый» относительно чего, по каким бенчмаркам |
| «Kubernetes сложный» | Оценка без критерия |

### Кажется мнением, но число
| Утверждение | Почему число |
|---|---|
| «Большинство разработчиков используют Git» | Доля, проверяется опросом (Stack Overflow Survey) |
| «Python популярнее Ruby» | Есть индексы (TIOBE, GitHub) — сравнение двух чисел |

### Кажется прогнозом, но уже событие
| Утверждение | Почему событие |
|---|---|
| «Python 4 выйдет в 2023» | 2023 прошёл, можно проверить (не вышел) |

### Кажется событием, но поведение
| Утверждение | Почему поведение |
|---|---|
| «Cogna купила медицинский факультет в Дорадосе» | Это событие. Но «холдинги скупают медицинские мандаты» уже поведение: обобщение нескольких сделок |
| «Школы запрещают ИИ» | Нет даты, есть регулярность; проверяется опросом или несколькими случаями |

### Заявлено, а не наблюдено
| Утверждение | Флаг |
|---|---|
| «5% россиян готовы отдать за вино больше 2000 руб.» | Поведение заявленное (опрос). Не подтверждает, что 5% так платят |
| «Владелец сети оценивает подарочную долю в 50%» | Поведение со слов оператора, не замер продаж |

### Кажется числом, но связь
| Утверждение | Почему связь |
|---|---|
| «Выручка холдингов — треть заявленного рынка» | Сравнение двух чисел с разными границами: холдинги торгуют дипломами, «рынок» — только технологическая часть |
| «В АСТ премиум даёт 6,5% в литрах и 32,5% в деньгах» | Две доли с разными знаменателями, сравнивать нельзя |

## Разметка источников

**Интерфакс, «Рыбные полуфабрикаты растут на 15% в год», 01.04.2026** — тип: СМИ.
Ссылается на ВАРПЭ (Герман Зверев) и NTech. Карточка: первоисточник — пересказ со ссылкой на спикера, полного отчёта нет; автор — редакция; мотивация — нейтральный канал, но ВАРПЭ как источник заинтересована в росте категории. Порядок проверки: сначала сверка с самой статьёй (в отчёте стояло «20,7 млрд руб.», в статье этого числа нет), потом поиск заявления ВАРПЭ или данных NTech напрямую.

**shishki-gastrobar.ru, «Рыба может занять 5% рынка готовой еды, 160 млрд к 2028»** — тип: блог / UGC.
Карточка: первоисточник не указан; автор — нет; мотивация — неясна; доступ к данным — нет. В определённость не входит. Число с влиянием 3 требует поиска первоисточника: кто именно дал оценку 5% и 160 млрд.

**Cogna, релиз за 3 квартал 2025** — тип: статистика / отчётность.
Карточка: первоисточник — да, PDF; автор — организация, отчётность перед инвесторами; мотивация — заинтересована, но отчётность регулируется; дата — ок. Проверять внутри: определение метрики (скорректированная EBITDA, прибыль с разовыми эффектами), границы объекта (Kroton внутри Cogna).

**Аналитик Itaú BBA через NeoFeed, «набор упал на 39% из-за ценовой стратегии»** — тип: эксперт (через СМИ).
Карточка: авторитетность — доступ к отчётности и компетентность есть; мотивация — банк-аналитик, нейтрален к компании, но заинтересован в резкости оценок; автор — назван. Кросс-чек: нужен второй аналитик или комментарий самой компании о причине падения набора.
