# chat-search — обслуживание

Поиск по истории чатов делает **субагент `chat-search`** (Sonnet, низкий
ризонинг — так быстрее). Если пользователь просто хочет что-то найти,
делегируй туда через Agent, а не выполняй поиск сам.

Этот скилл — про сам инструмент: состояние, обновление, починка.

## Команды

```bash
~/.local/bin/chat-search stats            # сколько чатов и сообщений в индексе
~/.local/bin/chat-search index            # обновить прямо сейчас
~/.local/bin/chat-search index --rebuild  # перестроить с нуля (~10 секунд)
```

## Проверка фоновой задачи

```bash
launchctl list | grep chat-search
tail -5 ~/Library/Application\ Support/chat-search/index.err
```

Во второй колонке вывода `launchctl` — код последнего запуска. `0` значит
всё в порядке. Если задачи нет в списке — переустанови, запустив
`scripts/install.sh` из папки этого скилла.

## Если правил скрипт

Исходник лежит в `scripts/chatsearch.py`, а работает копия в `~/.local/bin`
(macOS не пускает фоновые задачи в `~/Documents`). После правки исходника
запусти `install.sh`, иначе изменения не подхватятся.

## Устройство

Индекс — SQLite FTS5 с токенайзером `unicode61` в
`~/Library/Application Support/chat-search/index.db`.
Источники: `~/.claude/projects` и `~/.codex/sessions`. Cursor намеренно нет.

Подробности — в `README.md` рядом.
