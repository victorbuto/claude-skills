# chat-search

**Обновлено:** 3 ноября 2026
**Назначение:** единый поиск по истории чатов Claude Code и Codex
**Содержание:** описание, установка, команды, устройство индекса, субагент

## Description

Один поиск по всем разговорам с ИИ — и в Claude Code, и в Codex. Решает
задачу «я это где-то уже искал, но не помню где».

Собственный индекс на SQLite FTS5 с токенайзером `unicode61`. Он появился
потому, что готовые решения (CASS, claude-history) кириллицу не ищут вообще:
проверка на живых данных дала ноль попаданий по любому русскому слову при
работающем поиске по латинице.

Данные не покидают компьютер. Сети нет вообще — ни обновлений, ни телеметрии.

## Features

- **Русский поиск.** Окончания обрезаются автоматически: `сегментации` найдёт
  и `сегментация`, и `сегментацию`.
- **Оба инструмента в одной выдаче.** Claude Code и Codex вперемешку,
  отсортированы по релевантности.
- **Группировка по чатам.** Показывает не строчки, а разговоры: дата, проект,
  о чём был, сколько попаданий.
- **Чтение диалога целиком** командой `show`.
- **Само обновляется** раз в 5 минут через launchd. Инкрементально — трогает
  только изменившиеся файлы, полный проход занимает доли секунды.
- **Чистый индекс.** Служебные врезки IDE и системные напоминания выброшены.

## Как вызывается

Поиск делает **субагент `chat-search`** — Sonnet на низком ризонинге, чтобы
отвечал быстро. Работа тут механическая (подобрать слова, отфильтровать,
пересказать), тяжёлая модель не нужна. Определение — файл `chat-search.md`,
он должен лежать в `~/.claude/agents/` или в `.claude/agents/` проекта. В
публичной коллекции скиллов он лежит в папке `agents/` рядом с этим README.

Скилл `chat-search` остался только для обслуживания: состояние индекса,
ручное обновление, починка фоновой задачи. Триггеры у них не пересекаются,
чтобы не спорили за один запрос.

## Установка

```bash
./scripts/install.sh
```

Ставит `~/.local/bin/chat-search`, создаёт фоновую задачу и строит индекс.
Работает только на macOS: фоновое обновление сделано через launchd.

Рабочая копия скрипта лежит вне `~/Documents` намеренно: macOS не пускает
фоновые задачи в защищённые папки. Исходник — здесь, в скилле.

## Команды

```bash
chat-search search "сегментация оптик"      # найти чаты
chat-search search "бренд" --agent codex    # только Codex
chat-search search "гайд" --days 30         # за последний месяц
chat-search search "оптика" --any           # любое слово, не все
chat-search show <путь к сессии>            # прочитать диалог
chat-search stats                           # что в индексе
chat-search index                           # обновить вручную
```

## Устройство

| Что | Где |
|---|---|
| Индекс | `~/Library/Application Support/chat-search/index.db` |
| Логи | там же, `index.log` и `index.err` |
| Команда | `~/.local/bin/chat-search` |
| Фоновая задача | `~/Library/LaunchAgents/com.chatsearch.index.plist` |
| Источники | `~/.claude/projects`, `~/.codex/sessions` |

Cursor не индексируется намеренно.

## Что в индекс не попадает

Реплики человека и ответы модели — попадают. Не попадают: вызовы инструментов
и их результаты, содержимое `<ide_opened_file>` и `<system-reminder>`, вывод
команд. Это осознанное решение: иначе выдача забивается техническим мусором.

## Удалить

```bash
launchctl unload ~/Library/LaunchAgents/com.chatsearch.index.plist
rm ~/Library/LaunchAgents/com.chatsearch.index.plist
rm ~/.local/bin/chat-search
rm -rf ~/Library/Application\ Support/chat-search
```
