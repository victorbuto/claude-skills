# Followup Writer

## Задача

Из транскрипта или заметок встречи собрать фоллоу-ап, который можно сразу отправить участникам: плотный, фактурный, один экран.

## Процедура

1. **Вход**: путь к файлу транскрипта, вставленный текст или черновые заметки. Если входа нет — попросить транскрипт или заметки одним вопросом, без меню опций.
2. **Прочитать целиком** и выписать: deliverables (с цифрами и форматами), даты, имена, принятые решения, действия с владельцами, открытые вопросы.
3. **Определить 2–4 основные темы** встречи — они станут секциями. Побочные упоминания → «Прочее».
4. **Собрать фоллоу-ап по шаблону** ниже, соблюдая правила.
5. **Прогнать самопроверку** (чеклист в конце).
6. **Сохранить и выдать**:
   - Вход — файл транскрипта → сразу сохранить фоллоу-ап в новый `.md` файл в ту же папку, где лежит транскрипт. Имя: как у транскрипта, но `transcript` → `followup`; если слова `transcript` в имени нет — `<тема встречи>-followup-<дата>.md`. Существующие файлы не перезаписывать.
   - Вход — вставленный текст или заметки (файла нет) → только выдать текст в чат.
   - В обоих случаях выдать текст в чат готовым к копированию; при сохранении — указать путь к файлу.

Язык фоллоу-апа = язык встречи. Ничего не выдумывать: только факты из входа.

## Шаблон

```
[Лид-абзац без заголовка: 1–2 предложения]

[Тема 1 — короткий заголовок]
[факты списком]

[Тема 2 — короткий заголовок]
[факты списком]

Прочее            ← только если есть побочные упоминания
[факты списком]

Next Steps
(Кто) Глагол + конкретное действие + срок, если назван

Decisions Made
[только реально принятые решения]
```

## Правила

### Структура

1. **Лид-абзац** отвечает на три вопроса: что за встреча, главный deliverable, главная неопределённость. Кто прочитал только лид — уже в курсе.
   - Пример: «Синхрон по трендвотчингу для креативного воркшопа 13 августа на базе брифов фондов. Собирают 10-12 макротрендов в формате тренд-канваса; финальный формат уточнят после брифов».
2. **Секции по темам, не по хронологии.** Заголовки короткие («Воркшоп 13 августа», «Трендвотчинг»), никаких «сначала обсудили… потом…».
3. **«Прочее»** — отдельная секция для побочных упоминаний, чтобы не засорять основные темы. Нет побочного — секцию не создавать.
4. **Next Steps**: каждый пункт строго `(Кто) Глагол + конкретное действие + срок, если назван`. Имя спикера неизвестно из транскрипта — оставить `(Speaker 1)`, не угадывать. Владелец шага неясен — тоже Speaker N.
5. **Decisions Made отдельно** — только зафиксированные решения, не обсуждавшиеся варианты. Решающее правило: пункт попадает сюда, если участники явно договорились и вопрос закрыт.

### Язык

6. **Факты, не пересказ.** Запрещены глаголы-нарраторы: «обсудили», «поговорили», «было сказано», «затронули тему».
   - Плохо: «Обсудили, что нужны макротренды». Хорошо: «Нужно 10-12 макротрендов».
7. **Конкретика дословно**: цифры (10-12, 13 августа), имена (Лео, Саша), форматы (тренд-канвас, one-pager) сохраняются как прозвучали.
8. **Расшифровки в скобках** для читателя, которого не было на встрече: «Орби» (реабилитация после инсульта).
9. **Термины команды как есть**: «забрифоваться», «синк», «раздатки» — не переводить в канцелярит.
10. **Плотность**: без приветствий, выводов и воды. Каждая строка несёт информацию. Весь фоллоу-ап — один экран (~250–350 слов).

### Содержание

11. **Фиксировать неопределённости**: что ещё не решено и когда прояснится («круг поиска сузится после брифов»).
12. **Требования к deliverable — цифрами и форматом**: не «нужны тренды», а «10-12 макротрендов, презентация + раздатки one-pager».

## Самопроверка перед выдачей

- [ ] Лид отвечает на три вопроса: что за встреча / deliverable / неопределённость?
- [ ] Ни одного глагола-нарратора?
- [ ] Каждый Next Step в формате `(Кто) Глагол + действие + срок`?
- [ ] В Decisions Made — только закрытые вопросы?
- [ ] Все цифры, имена и даты из входа сохранены дословно?
- [ ] Умещается в один экран?

## Эталонный пример

```
Синхрон по трендвотчингу для креативного воркшопа 13 августа на базе брифов фондов «Орби» и «Обычное дело». Собирают 10-12 макротрендов в формате тренд-канваса; финальный формат уточнят после брифов и обсуждения с креаторами.

Воркшоп 13 августа
Креативный воркшоп для стратегов, продюсеров, артов на базе брифов двух благотворительных фондов
Фонды: «Орби» (реабилитация после инсульта) и «Обычное дело» (адаптация маломобильных, ментальные особенности)

Трендвотчинг
Нужно 10-12 макротрендов (культурные, социальные, политические, экономические), сгруппированных для команд
Формат: презентация + раздатки в виде тренд-канваса (one-pager на тренд)
Круг поиска сузится после брифов с фондами
Обсудить с креаторами формат, чтобы тренды были пригодны для генерации креатива, не сухая инфа

Прочее
Виктор Буто показал Wispr: живая транскрипция и суммари по промту

Next Steps
(Speaker 1) Забрифоваться с фондами «Орби» и «Обычное дело» завтра и послезавтра
(Speaker 1) Договориться со вторым креатором Лео
(Speaker 1) Поставить общий синк после второго брифа
(Speaker 1) Запланировать колл с креаторами (Саша и Лео) для обсуждения формата трендов
(Виктор Буто) Написать Лизе, если понадобится подключение

Decisions Made
Trendwatching deliverable в формате презентации с раздатками по тренд-канвасу
Два фонда для воркшопа: «Орби» (реабилитация после инсульта) и «Обычное дело» (адаптация маломобильных)
```
