# Claude Skills

Коллекция моих персональных скиллов для Claude Code — для стратегии, исследований, бренд-анализа и коммуникаций.

## Description

Скиллы расширяют возможности [Claude Code](https://claude.com/claude-code): задают воркфлоу, промпты для параллельных агентов, шаблоны итоговых документов. Каждый скилл — самодостаточный модуль с `SKILL.md` и опциональными `references/`, `scripts/`, `assets/`.

## Features

### [brand-analysis](skills/brand-analysis)
Глубокий разбор одного бренда: позиционирование, ToV, ЦА, RTB, консистентность коммуникации. Три параллельных агента собирают сырьё (сайт и продукты / соцсети и ~15 постов / реклама через `erid`-маркер, спецпроекты, PR-кейсы), потом синтез в итоговый файл с 12 блоками анализа.
**Как запустить:** «разбери бренд», «анализ позиционирования», «brand analysis», «ToV бренда».
**Инпут:** название бренда и сайт.
**Выход:** 4 файла в `Researches/[slug]/` — 3 сырьевых + `brand_analysis.md`.

### [research-design](skills/research-design)
Помогает правильно поставить задачи исследования: уточняет бизнес-контекст по SPICE, формулирует цель и гипотезы, даёт фидбэк по критериям качества. Полезен на старте customer research, UX-интервью, конкурентного анализа.
**Как запустить:** «помоги поставить задачи исследования», «проверь гипотезы», «готовлюсь к исследованию».
**Инпут:** описание задачи / черновик вопросов.
**Выход:** набор целей, задач, гипотез + фидбэк по формулировкам.

### [qual-research-design](skills/qual-research-design)
Дизайн качественного полевого исследования: разбивка по сегментам, выбор метода (глубинные интервью / фокус-группы / экспертные), расчёт количества на сегмент. Для коммуникационных и бренд-проектов.
**Как запустить:** «дизайн исследования», «сколько интервью нужно», «разбивка по сегментам», «план полевого».
**Инпут:** контекст проекта (бриф, ЦА, цели).
**Выход:** таблица с сегментами, методами и количеством.

### [segmentation-hypotheses](skills/segmentation-hypotheses)
Выбор метода сегментации аудитории и формулировка первичных гипотез сегментов. Основан на методологии Gopractice (28 методов с оценками Ч/Р/Д). Подходит для продуктов и бренд-стратегий.
**Как запустить:** «сегментация», «гипотезы сегментов», «как сегментировать», «какой метод сегментации».
**Инпут:** описание продукта, рынка, ЦА.
**Выход:** 2–3 подходящих метода с гипотезами сегментов и рекомендациями.

### [Deep-web-search](skills/Deep-web-search)
Продвинутый поиск по методу Slice: генерация ключевых запросов, параллельные поисковые подагенты, сведение результатов. Помогает пробиться через коммерческий шум и найти информацию глубже первых результатов Google/Яндекса.
**Как запустить:** «найди информацию», «research», «помоги составить запросы», или когда обычный поиск не даёт результата.
**Инпут:** исследовательский вопрос.
**Выход:** сводный отчёт с находками из нескольких поисковых стратегий.

## Установка скилла

Скопируй нужный скилл в папку скиллов Claude Code:

```bash
# глобально (все проекты)
cp -R skills/brand-analysis ~/.claude/skills/

# в конкретный проект
cp -R skills/brand-analysis /path/to/project/.claude/skills/
```

Или через симлинк — тогда правки в репо сразу видны в Claude Code:

```bash
ln -s "$(pwd)/skills/brand-analysis" ~/.claude/skills/brand-analysis
```

После установки перезапусти Claude Code, чтобы он увидел новый скилл.

## Как пользоваться

Скиллы в Claude Code запускаются автоматически по триггерам в `description` (в YAML-шапке `SKILL.md`). Достаточно написать запрос в естественном формате — например, «разбери бренд Тинькофф» — и Claude сам подхватит нужный скилл.

Можно вызвать и явно: `/skill-name` (если скилл поддерживает user-invocable).
